# learning-go

Documenting my journey of learning Go. Includes notes, examples, and small practice programs inspired by resources like Go by Example and other tutorials.

This repo is organized by year, so each round of learning stays separate.

| Year | Notes |
| ---- | ----- |
| [2025](2025/README.md) | First pass: arrays, slices, maps, pointers, structs |
| [2026](2026/) | Picking it back up after a break |

## Layout

```
learning-go/
├── go.mod              # single module for the whole repo
├── 2025/
│   ├── cmd/playground/ # runnable entrypoint
│   └── topics/         # example files per topic
└── 2026/
```

## Quick start

```bash
go run ./2025/cmd/playground
```

## Notes

- This repo is intended as a personal learning journal rather than a production library. Use it for reference and experimentation.
